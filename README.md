# discourse-kuu-ratings

京大中文论坛（KUU）的虎扑式评分插件。

- **评分主题**：例如「百万遍周边拉面」，里面有多个**评分对象**
- 每个注册用户对每个评分对象打一次 **0–10 分**，短评选填
- 不能改分，可以删除自己的打分后重新打
- 所有注册用户都能发起评分主题、添加评分对象，两者都要经过管理员审核
- 热评就是点赞最多的短评

评分主题和评分对象都是普通的 Discourse 帖子，审核、举报、点赞、通知、搜索都直接用 Discourse 自带的功能。插件只负责记录打分、计算平均分、展示评分界面。
